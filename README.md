# Change Project Management Dashboard

An interactive Power BI dashboard designed to monitor project tasks, task status, approvals, overdue work, priorities, and Core IT projects.

## Project Overview

This project transforms project management data into an interactive dashboard that provides a clear view of workload, task progress, and outstanding actions.

The dashboard was designed to help project teams quickly identify:

- Total number of tasks
- Tasks currently in progress
- Overdue tasks
- Tasks awaiting approval
- Core IT projects
- Task distribution by status
- Task distribution by project bucket
- Individual project task details

## Dashboard Features

### Project Management Dashboard

The main dashboard includes:

- KPI cards for key project metrics
- Tasks by Status visualization
- Tasks by Bucket visualization
- Interactive filters for Bucket and Task Status
- Detailed project task table
- Overdue task tracking
- Priority and due-date information

### Assigned Projects Dashboard

A separate dashboard provides an assigned-project view with:

- Assigned Analyst filter
- Technical Lead filter
- Total Assigned Tasks
- In Progress tasks
- Awaiting Approval tasks
- Overdue Tasks
- Detailed assigned-project task table

## Key Metrics

The completed dashboard provides KPI tracking for:

| Metric | Description |
|---|---|
| Total Tasks | Total number of project tasks |
| In Progress | Tasks currently being worked on |
| Overdue Tasks | Tasks past their due date and not completed |
| Awaiting Approval | Tasks currently awaiting approval |
| Core IT Projects | Tasks associated with Core IT projects |

## Project Outcome

The dashboard provides a centralized and interactive way to monitor project activity, identify outstanding work, and quickly assess project status.
